### About This Repository

This repository serves as the public distribution point for **Wick**. It contains downloadable builds along with version-by-version release notes.

Wick is a **proprietary** application. This repository is limited to release artifacts and related documentation only.

### Feedback & Issues

If you encounter a bug or have a suggestion for improving Wick, please open an issue so it can be tracked and reviewed.

### Stay Connected

Wick has a [Discord](https://discord.gg/ztBsd53F3T) where users can ask questions, share feedback, and follow development updates. You’re welcome to join.
