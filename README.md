# Wick Releases

Wick is a free macOS clock replacement. While Wick is free, it is not an open-source project, so this repo only contains releases of Wick.

If you encounter any issues or have ideas, please file them in the Issues tab.

You can also contact us at hello@trywick.co or join our [Discord community](https://discord.gg/9QDUn9v24Y).
